# UX/UI и пользовательский опыт «НейроДиета»

## Карта пользовательского пути (User Journey)
1. Первый запуск → онбординг (цели, привычки, устройства)
2. Главная (дашборд): виджеты питания, активности, воды, совет ИИ
3. Подключение гаджетов → синхронизация (сон, пульс, стресс, вес)
4. Питание: добавление еды (поиск/штрихкод/фото), «Рецепт из холодильника»
5. Тренировка: выбор программы → запуск AI-тренера
6. Прогресс: графики веса/жира/мышц, фото до/после, AI-инсайты
7. Вызовы и дуэли: создание, приглашение друга, прогресс в реальном времени
8. Список покупок: автогенерация по плану → заказ доставки
9. Чат «Нейро»: мотивация, поддержка, КПТ-техники, проактивные напоминания

## Ключевые экраны прототипа
- Регистрация: соцсети и email
- Онбординг-диалог: короткие вопросы, адаптивный тон
- Дашборд: карточки «Питание/Активность/Вода/AI-совет»
- Питание: поиск, сканер штрихкода, фото-распознавание, «рецепт из холодильника»
- Тренировки: библиотека программ, экран сессии AI-тренера (камера+подсказки)
- Прогресс: графики, фото, AI-инсайты
- Вызовы/Дуэли: лента вызовов, экран соревнования
- Список покупок: группы по отделам, кнопка «Заказать доставку»
- Чат «Нейро»: диалоги, быстрые ответы, реакции

## Нижняя панель навигации (Таб-бар)
- **5 кнопок**: Главная, Питание, Тренировка (центральная), Прогресс, Нейро
- **Цвета**: центральная кнопка — зелёный `#2ECC71`; активная вкладка — синий `#3498DB`; остальные — серый
- **Поведение**: всегда видна, кроме экрана активной тренировки и при открытой клавиатуре
- **Анимации**: лёгкая вибрация/подсветка при нажатии центральной кнопки

## UX-принципы
- Прогрессивное раскрытие сложных функций
- Микромотивация и обратная связь на каждом шаге
- Адаптивность под цель, уровень и доступные устройства
